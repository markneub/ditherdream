# ditherdream

A 1-bit renderer experiment inspired by *Return of the Obra Dinn*: seven small scenes drawn in two
colours, with halftone dots that stay glued to surfaces as the camera moves. Ship's deck, below decks,
lighthouse, forest at night, cathedral, night train, desert ruins.

Live at https://markneub.github.io/ditherdream/ or open `index.html` in any WebGL2 browser. "Scenes" switches scene. Drag to orbit, pinch or scroll to zoom; "Walk" puts you on foot.

`npm install && npm run shots` renders reference screenshots into `shots/`.

See [CLAUDE.md](CLAUDE.md) for how it works and what to try next.

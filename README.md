# ditherdream

A 1-bit renderer experiment inspired by *Return of the Obra Dinn*: a moonlit ship drawn in two
colours, with halftone dots that stay glued to surfaces as the camera moves.

Open `index.html` in any WebGL2 browser. Drag to orbit, pinch or scroll to zoom.

`npm install && npm run shots` renders reference screenshots into `shots/`.

See [CLAUDE.md](CLAUDE.md) for how it works and what to try next.
